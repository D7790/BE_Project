## Findings and corrections

1. **Previously ignored CAD rules:** enabling every ignored category in a scratch copy exposes six `footprint_filter` warnings in ERC and the corresponding six `footprint_filters_mismatch` parity warnings in DRC, all J1–J6. The generic connector symbol's filter does not match the Phoenix library name. Independent checks confirm the actual footprint assignments, two pin nets, 5.08 mm pitch and 1.3 mm drills. No geometric/connectivity defect or other all-rule warning was found. The warnings are documented in the manuscript and audit; the released design was not changed to suppress them.
2. **Execution-method ambiguity:** Section IV now states that the coupled discharge model runs the Python reference controller, while production C++ logic is tested separately on the host. It does not claim firmware-in-the-loop evidence.
3. **Notation drift:** energy/runtime notation is consistently `E_est`/`T_est` across editable source, rendered equations and Figure 2.
4. **Missing local evidence mapping:** the paragraph discussing identical plant/estimator inputs now cites the actual model evidence as well as literature in the internal claim registry.
5. **Weak numerical checker:** the old consistency registry repeated values from the same summary. A new checker now compares actual manuscript prose and table cells with data and verifies all abstract/prose paragraphs occur in the PDF. Negative fixtures establish that deliberate mismatches fail.
6. **Stale artifacts and automatic QA:** the PDF build now binds input and output hashes. Packaging reruns current checks and requires a separately recorded review bound to the PDF and every page render. It cannot create a visual-review approval itself. Figure QA hashes and the editable Word's inputs are checked too.
7. **Rebuild preservation:** record preparation no longer overwrites existing authorship, policy or reporting declarations. Nothing has been marked human-approved.
8. **PDF banner clipping:** visual inspection found the draft banner absent on some figure pages. A separate PDF overlay fixes it; the banner is visible on all seven final pages.

No production firmware, controller model, hardware geometry, BOM or arming flag was modified during this recheck. Prior reports and before-change artifacts are retained under `evidence/recheck-2026-09-30/`.
