Source inspection
- The deployed source samples voltage/current and policy at nominal 10 Hz,
  temperature and telemetry at nominal 1 Hz. Reboot and invalid/gapped samples
  invalidate SOC; the saved checkpoint is diagnostic only.
- INA219 decoding rejects failed reads, reset/configuration/calibration mismatch
  and overflows. Sequential reads are not claimed to be an atomic ADC frame.
- Both controllers use signed charge integration, the same 20% reserve and
  nominal-voltage energy heuristic, a 3 s sustained threshold, a latched optional
  load, and explicit restoration with 0.25 h additional margin. Firmware adds
  the physical hardware lock and estimates restoration using a provisional
  3.5 W increment. The reference model accepts prospective full-load power.
- The reference model's automatic=false option is used to form the baseline;
  this is not a firmware operating mode. Simulator scenarios and reference SOC
  seeding are explicitly simulation functions, not remote hardware control.
- Hardware serial data require protocol=1 and source_mode=hardware, correct
  types, finite values and consistency checks. Unknown/partial/oversized frames
  are discarded. Hardware sessions have no command forwarding to the serial
  device. The HTTP service binds 127.0.0.1, checks Host and Origin, and rejects
  hardware control requests; the UI marks stale data and uses textContent for
  incoming textual fields.
- Physical control governs only the optional fan. The essential lamp has no
  automatic disconnect; the operator must end reserve experiments as documented.

Limits and next physical checks
Compilation, synthetic traces, native host tests and equations do not establish
real sensor accuracy, usable pack capacity, startup behaviour, regulator/ESP32
brownout performance, component temperatures, fuse clearing, BMS behaviour,
EMC, or whole-system safety. The OCV curve and loss parameters remain assumed.
Measure the selected battery, shunts, converter and actual loads; perform the
documented current-limited bring-up and calibration before enabling control.
Compare policy runs at the same measured initial condition and stopping rule.
Record fan service along with lamp service; the model gains lamp service by
reducing fan service, not by increasing battery capacity or converter efficiency.
